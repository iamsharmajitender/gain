# MCP Playbooks

[Playbooks](/playbooks) · **MCP overview** · [Manifest registry →](/playbooks/agents/manifests/manifest-registry)

Implementation guides for [G.A.I.N MCP](/frameworks/gain-mcp). The [MCP Blueprint](/blueprints/mcp-blueprint) is the reference design for MCP as **transport**. The tool contract (what the LLM may propose) lives in the [Agents Blueprint](/blueprints/agents-blueprint) under Manifests. How-to: [Agents: Manifests](/playbooks/agents/manifests/manifest-registry). MCP is one way to expose those tools, not the catalog.

PEP still gates every tool side effect. Enforcement lives in [Runtime](/playbooks/governance/runtime).

:::tip[THE CLAIM]
**MCP is a governed capability surface, not the tool allowlist.** The pinned manifest is the contract. MCP, OpenAPI, and domain APIs are adapters.
:::
